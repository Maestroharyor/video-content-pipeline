The preference
Cursors beat offsets
on big, moving data
Offset
LIMIT 20
OFFSET 10000
Counts past every row it skips, and re-numbers itself the moment a row is inserted.
Cursor
WHERE id < 4818
LIMIT 20
Seeks straight to a known row. Inserts above it change nothing at all.
Use a cursor when the dataset is large, or when it changes while people are reading it.
Large tables
Live inserts
Deep pages
Cursor wins all three.
Offsets are fine for a small, static table. Most product data is neither.
